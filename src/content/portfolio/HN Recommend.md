HN Recommend is a recommendation engine for Hacker News. Using embeddings and [Faiss](https://github.com/facebookresearch/faiss), I was able to compute the most similar articles to a given one. The project is available on [https://hn-recommend.julienc.me](https://hn-recommend.julienc.me)

> The project is now transfered to the Alexandria library. You can find it [here](https://alexandria-library.julienc.me)

I recommend reading the articles associated with this project  [here](https://julienc.me/articles/extract_embeddings_hacker_news_article)
